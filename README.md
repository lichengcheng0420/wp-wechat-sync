# WP WeChat Sync (微信公众号文章同步助手)

为 WordPress 打造的微信公众号文章同步插件。在 WordPress 中撰写或发布的文章可自动或一键同步到微信公众平台草稿箱（或直接公开发布）。

---

## 主要特性

1. **对接微信官方最新草稿箱接口**：采用官方推荐的 `cgi-bin/draft/add` 接口，同步后可在微信公众平台后台预览、排版微调、群发或定时发布。
2. **正文图片自动转存微信永久 CDN**：自动提取文章中的所有 `<img>` 本地及外链图片，调用微信 `cgi-bin/media/uploadimg` 接口转存至微信 CDN 并替换链接，彻底解决微信文章外链防盗链及图片裂图问题；支持本地 CDN 映射缓存，避免重复上传。
3. **封面图智能提取**：按优先级自动提取：文章特色图像（Featured Image） > 正文第一张图 > 全局默认封面图，自动上传永久素材库获取 `thumb_media_id`。
4. **服务器公网出口 IP 自动识别**：微信公众平台强制校验调用方 IP 白名单。插件在后台直观展示当前服务器公网出口 IP，支持一键复制，避免配置白名单时盲猜 IP。
5. **API 连接一键测试**：在插件后台填写 AppID 和 AppSecret 后，可直接点击“测试 API 连接”，实时校验凭据有效性与 IP 白名单配置，提供清晰的中文错误指引。
6. **文章编辑页侧边栏组件**：
   - 实时显示文章同步状态（未同步 / 已同步至草稿箱 / 同步时间 / 草稿 ID）。
   - 提供**“立即同步到公众号”** AJAX 按钮，无需重新保存文章即可手动一键同步。
   - 支持文章级别的自定义微信作者、自定义微信摘要（自动限制 120 字）、禁止自动同步开关。
7. **文章列表页快捷状态展示**：在后台文章列表（`wp-admin/edit.php`）增加“微信同步”状态列，直观显示已同步状态及快捷“同步/重试”链接。
8. **详细日志追踪与排查**：记录最近 50 条同步历史（包含自动同步、手动同步、测试连接的请求与返回详情），方便快速排查异常。

## 安装与使用指引

### 1. 启用插件
进入 WordPress 后台 -> **插件** -> **已安装插件**，找到 **WP WeChat Sync (微信公众号文章同步助手)** 并点击 **启用**。

### 2. 获取微信开发者平台凭据与配置 IP 白名单
1. 登录 [微信开发者平台](https://developers.weixin.qq.com/platform/)（或 [微信公众平台](https://mp.weixin.qq.com/)）。
2. 选择对应公众号，进入 **“基础信息”** 页面。
3. 在 **“开发密钥”** 区域：
   - 复制 **开发者ID (AppID)**。
   - 点击 **重置** 开发者密码获取 **AppSecret** 并妥善保存。
   - 在 **API IP白名单** 点击 **编辑**，将 WordPress 插件后台提示的 **当前服务器公网出口 IP** 粘贴加入，管理员扫码确认保存。

### 4. 插件配置与测试
1. 在 WordPress 后台 **设置 -> 微信同步** 中，填写 **AppID** 和 **AppSecret**。
2. 点击 **测试 API 连接**，确认显示“连接成功！已顺利获取到 Access Token”。
3. 根据需要配置：
   - **同步目标**：推荐选择“同步至草稿箱”。
   - **自动同步开关**：发布新文章时是否自动同步。
   - **全局默认封面**：选择一张默认图片作为保底封面（微信图文必须有封面）。
   - **原文链接与版权**：开启微信底部的“阅读原文”直达 WordPress 原文。
4. 点击 **保存设置**。

### 5. 开始同步文章
- **自动同步**：撰写新文章并点击“发布”时，插件将自动转存图片并推送到微信公众平台草稿箱。
- **手动同步**：在文章编辑页右侧侧边栏“微信公众号同步”面板中，点击 **立即同步到公众号** 即可。

## 目录结构

```text
wp-content/plugins/wp-wechat-sync/
├── wp-wechat-sync.php                 # 插件入口主文件
├── README.md                          # 插件说明文档
├── includes/
│   ├── class-wechat-api.php           # 微信官方接口封装与错误码中文化
│   ├── class-post-sync.php            # 文章内容转换、图片转存与同步核心逻辑
│   ├── class-admin-settings.php       # 后台设置页面与 AJAX 处理器
│   ├── class-meta-box.php             # 文章编辑页侧边栏组件与列表列
│   └── class-sync-logger.php          # 同步历史与错误日志记录器
└── assets/
    ├── css/admin.css                  # 后台美化样式表
    └── js/admin.js                    # 设置页与编辑页交互脚本
```
